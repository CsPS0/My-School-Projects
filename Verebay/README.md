## Naming

- `YY-MMDD_Topic`: the date the work was done, e.g. `23-0322_Busojaras` is 22 March 2023. A range such as `23-0123-0127` is a project week.
- Folders without a date: the exact date is unknown.
- `_v2`, `_v3`: later versions of the same assignment. `_befejezetlen` or `_nem-kesz`: an unfinished version.
- `PYTHON/Egyeb` in 10th grade: scripts with no date. They were in the same folder as the 10th-grade work, so they are filed there.
