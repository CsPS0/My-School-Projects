# FizzBuzz TDD Feladat

## Refaktorálás
A fejlesztés végén, miután minden teszt sikeresen lefutott (Zöld fázis), a kódot átláthatóbbá tettem a modulo operátorok használatával és a felesleges elágazások eltávolításával, így a logika sokkal tömörebb és olvashatóbb lett, illetve a  felesleges Spaceket kihagytam, hogy ne legyen sorhiba.
