# User Documentation - World Wide Dashboard

## Introduction
The **World Wide Dashboard** is a centralized interface where you can track the most important global and local data. You no longer need to visit separate pages for Steam statistics, YouTube trends, or election results – everything is in one place.

## Using the Home Screen
Upon opening the website, you will find various data modules (widgets) on the main page, displayed on an elegant, dark-themed, glassmorphism interface:

- **Games:** You can track current Steam player counts (global statistics). If you provide your Steam ID, you can also see your own Last Played data! It also supports linking Tracker.gg and Exophase accounts for cross-platform statistics.
- **Video & Media:** 
  - **YouTube Stats:** You can choose from the most popular content creators, or set up your own YouTube channel.
  - **Music:** Follow global top lists (based on Spotify/SoundCloud/Last.fm), or connect your personal "Now Playing" Last.fm profile.
- **Finance:** Current dollar and euro exchange rates for cryptocurrencies (Bitcoin, Ethereum, Hawk Tuah Coin), as well as real-time EUR/HUF currency exchange rates.
- **Politics:** Statistics related to Hungarian election data and profiles of world leaders.

The interface is equipped with fluid animations (Anime.js) and features a unique Narnia-themed 404 error page.

## Settings and Customization
Under the new **Settings** tab, you can personalize how your Dashboard operates:
- **Compact View:** In the "Dashboard Layout Options" menu, you can toggle the compact card view or let the page fill the entire screen (Full-width).
- **Personal Accounts (API Keys):** You can enter your own Steam ID, YouTube channel, Last.fm username, and Tracker.gg links (R6, LoL, RL). The provided links will automatically load your personal data into the cards on the main page!

## Data & Privacy
By clicking the **Privacy** button in the top right corner, you can access our detailed Privacy Policy. Here you can transparently see which modules use live, real API connections (Steam, YouTube, Last.fm, CoinGecko), and which modules work purely with simulated (Mock) data for user security and the nature of the project (for example, the 2026 Hungarian political elections and the traditional stock market).
By clicking the **License** button, you can view the project's official, open-source MIT License documentation in a modern, built-in interface.

## Frequently Asked Questions (FAQ)
- **How often is the data updated?**
  - The application has a built-in Cache. Data fetching occurs in the background and is automatically refreshed every 5 minutes to avoid API limitations.
- **Is the site accessible from mobile devices?**
  - Yes, the website is fully responsive, so it displays flawlessly on phones and tablets.
- **Is the service free?**
  - Yes, every feature of the Dashboard is open and completely free to use.
